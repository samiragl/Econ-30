What HTML is (in one minute)

HTML is the skeleton of a webpage.

It tells the browser what everything is — title, text, images, links.

Think of it like labeling parts of a document:

  • "this is a heading"
  • "this is a paragraph"
  • "this is a link"
  • "this is an image"

Step 2: Paste this full prompt in Plan Mode

Create a single-file capstone webpage and help me in two phases.

Phase 1 (Plan):
- First propose a short step-by-step plan only.
- The page must include:
  1) Project title
  2) My name
  3) Project description with context, short literature summary, and research question
  4) One interactive element (details/summary is fine as a placeholder)
- Keep styling clean and simple, academic look, readable spacing.

Phase 2 (Implement after I approve):
- Generate index.html with semantic HTML and minimal embedded CSS.
- Then give me a short local test checklist.
- Then give me Vercel deploy steps for a static page.

Do not skip the planning step.

Step 6: Local quality check

  • Open index.html in your browser.
  • Verify all required sections are present.
  • Check that your research question is clearly visible.
  • If you added an image, confirm the path works.
  • Click your interactive element to make sure it behaves as expected.

Step 7: Deploy on Vercel

  1. Push your project to GitHub.
  2. In Vercel: New Project → import your repository.
  3. Use static / Other settings if asked.
  4. Deploy and copy the public URL.

After edits: push again and redeploy so your URL shows the latest version.
