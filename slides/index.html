Why this assignment

One public URL — anyone can open the project without extra software.

  • Explain context, literature, and a clear research question.
  • Package work for non-specialist readers.
  • Practice publish: local file → hosted page.
Tie to economics communication: question, evidence, accessible summary.

What students turn in

1. index.html

  • Project title and student name
  • Description: context, literature, research question
  • One interactive element — placeholder or figure OK

2. Live link

Hosted on Vercel, public. Cursor allowed; Plan Mode recommended.

One slide they can screenshot as the checklist anchor.

What HTML is (one minute)

HTML = structure + content.

  • Structure: html, head, body, headings, section, p
  • Media: img, a to papers or data
  • Interactive (assignment): collapsible, button, form, chart placeholder…

Not a full web course — map ideas to their page sections.

Minimum viable layout

[ Project title + name ]
[ Context / motivation     ]
[ Literature (short)       ]
[ Research question        ]
[ Interactive / figure     ]
[ Optional: links, footer  ]

Tags: h1–h3, p, section, figure, img, a, details/summary, button

Interactive element (keep it small)

  • details / summary — expandable methods or data
  • Placeholder — “Chart here” in figure or bordered div
  • Simple form — static HTML; no server for this HW
  • Optional: tiny JS demo if you choose to show it

Placeholder satisfies the requirement if the real interaction is not ready.

Plan Mode

When: first HTML + deploy; multiple steps at once.

Example ask:

Break into steps: (1) semantic HTML skeleton,
(2) simple CSS for readability,
(3) one interactive placeholder,
(4) checklist for static deploy on Vercel.
Students execute step-by-step vs one vague “make my website.”

Prompts: weak vs strong

Weak: “Make my website for my capstone.”

No sections, audience, design, or file plan.

Stronger shape:

Create a single-file index.html for my economics capstone.
Sections: title + name; motivation; 3–5 sentence lit summary;
research question emphasized; one details/summary block.
Design: academic, max-width ~720px, system fonts, whitespace.

What students should paste

  • Content: title, name, context, references, precise RQ
  • Design: columns, colors, tone, image paths if any
  • Tech: single file vs folder — match deploy instructions

TA tip: outline + design in the same first message.

Before Vercel: local check

  • Static site — no server code required for this assignment
  • Open index.html in the browser
  • Fix image paths (relative to the HTML file)
  • Prefer lowercase index.html at deploy root

If it fails locally, hosting will not fix it.

Hosting on Vercel

Goal: production URL anyone can load.

Primary path — Git + Vercel

  1. Push project to GitHub
  2. Vercel → New Project → Import repository
  3. Framework: Other / static if prompted
  4. Root must contain index.html (or set subdirectory)

Teach one path in lecture; document alternates in course docs if needed.
